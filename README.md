# TN

Заметки в виде телеграм-чата.

Приложение ведёт заметки как переписку с самим собой: чаты-темы, сообщения, фото, хэштеги. Написано на Python + Flet.

![TN](assets/icon.png)

## Возможности

- Чаты-темы (например «Идеи», «Работа», «Избранное») с иконками и цветами
- Записи как сообщения: текст, фото, видео, списки дел (TODO)
- Списки дел с чекбоксами: отмечайте выполненное прямо в чате
- Хэштеги `#тег` в тексте
- Поиск по всем чатам и записям с переходом к найденному сообщению
- Переслать / изменить / удалить запись (долгое нажатие на сообщение)
- Светлая и тёмная темы
- Язык интерфейса: русский, английский, украинский, немецкий, испанский, французский
- Данные хранятся локально на устройстве

## Запуск

```
pip install -r requirements.txt
python main.py
```

## Сборка APK

```
flet build apk
```
